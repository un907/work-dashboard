# スプレッドシート → ダッシュボード 市場調査レポート

調査日: 2026-03-19

---

## 1. 直接競合 — スプレッドシートからダッシュボードを生成するツール

### 1.1 Google Looker Studio (旧 Data Studio)

- **概要**: Google提供の無料BIツール。Google Sheets を直接データソースとして接続し、リアルタイムダッシュボードを作成
- **料金**: 完全無料
- **強み**:
  - Google エコシステムとのネイティブ連携 (GA4, BigQuery, Sheets, Ads)
  - 無料で始められるため、中小企業・スタートアップの最初のBIツールとして選ばれやすい
  - 2026年にはGoogle Sheetsから直接Looker Studioレポートを作成可能に
- **制限・弱点**:
  - **パフォーマンス劣化**: 100,000行を超えるとパフォーマンスが大幅に低下。Google Sheets接続は500,000セル以下が推奨
  - **データブレンディング上限**: 5ソースまで
  - **読み込み速度**: レポート読み込みに2〜6分かかることがあり、チームメンバーが1日20〜80分浪費するケースも
  - **モバイル体験が貧弱**
  - **ブランディングカスタマイズが制限的**
  - **非Google データソースのコネクターは高額な有料サードパーティ製**
  - G2レビュー（2025年）の38%がパフォーマンス問題を指摘
- **技術スタック**: Google Cloud ベース、プロプライエタリ

### 1.2 Geckoboard

- **概要**: KPIダッシュボード特化。TVモニター表示向けのリアルタイムダッシュボード
- **料金**:
  - Essential: $149/月 (5ダッシュボード, 3ユーザー, 1 TV共有)
  - Pro: $199/月 (5ダッシュボード, 10ユーザー, 3 TV共有)
  - Scale: $699/月 (30ダッシュボード, 25ユーザー, 10 TV共有)
- **強み**: シンプルなUI、TV表示に最適化、Salesforce/Google Sheets連携
- **弱点**: 高価格帯、カスタマイズ性が限定的、ダッシュボード数が少ない

### 1.3 Klipfolio (Klips)

- **概要**: 130以上のデータソースに対応するKPIダッシュボードプラットフォーム
- **料金**:
  - Free: 無制限メトリクス, 2エディター, 2ダッシュボード
  - Go: $125/月
  - Pro: $300/月 (優先サポート)
  - Business: $800/月〜 (年間契約のみ)
- **強み**: データソースの豊富さ（130+）、無料プラン有り
- **弱点**: 学習コストが高い、UI がやや古い

### 1.4 Chartbrew

- **概要**: オープンソースのレポーティングプラットフォーム。API, SQL, NoSQLデータベースからダッシュボード作成
- **料金**: セルフホスト無料 / クラウド版は有料（具体価格は要確認）
- **強み**:
  - 100%オープンソース（GitHub: chartbrew/chartbrew）
  - AI アシスタント（ベータ）でチャットからチャート・ダッシュボード生成
  - 埋め込み可能なチャート
  - Slack/メール/Webhookへのスナップショット自動配信
- **弱点**: Google Sheets のネイティブ統合は不明確。MongoDB, MySQL 等のDB接続が主力
- **技術スタック**: Node.js, React, MongoDB/MySQL 対応

### 1.5 Rows.com

- **概要**: モダンなスプレッドシート。50以上のデータソースと統合し、ダッシュボード機能を内蔵
- **料金**:
  - Free: 無制限メンバー, 10,000統合タスク, 時間単位自動化
  - Plus: $8/ユーザー/月 (月払い) / $6/ユーザー/月 (年払い), 100,000タスク
  - Pro: $79/月基本 + $8/ユーザー/月, 1Mタスク, 分単位自動化
- **強み**: Google Analytics, Search Console, Facebook Ads, Notion, BigQuery と統合。AI分析機能。スプレッドシートUIのまま可視化
- **弱点**: Google Sheets の代替であり、既存 Sheets からの移行が必要

### 1.6 Actiondesk

- **概要**: ライブデータで動くスプレッドシート。Shopify, Stripe, HubSpot, MySQL, Google Sheets 等を統合
- **料金**: 非公開（ベンダーに直接問い合わせ）
- **強み**: リアルタイムデータ同期、多数のSaaS連携、ピボットテーブル・チャート内蔵
- **弱点**: 価格不透明、個人利用には向かない可能性

### 1.7 Coupler.io

- **概要**: ノーコードデータ統合プラットフォーム。700+統合。データをウェアハウス、スプレッドシート、BI、ダッシュボードに送信
- **料金**:
  - Professional: $132/月 (25接続, 5ユーザー)
  - Business: $599/月
- **強み**: 15分間隔のスケジュール更新、データ変換機能内蔵
- **弱点**: 高価格帯、ダッシュボードは付随機能で主力ではない

### 1.8 Coefficient

- **概要**: Google Sheets / Excel 内でライブデータ接続・ダッシュボード構築を実現
- **料金**: Pro $99/月 (10ユーザーまで)
- **強み**: スプレッドシートを離れずにライブダッシュボード構築、AI Sheets Assistant、双方向同期
- **弱点**: スプレッドシート内での表現に限界がある

### 1.9 Datapad

- **概要**: ゼロ知識でも数秒でレポート構築可能なダッシュボードツール。AI プロンプトで生成
- **料金**: 無料プラン有り（詳細は要確認）
- **強み**: 極めてシンプル、AI生成、無料テンプレート豊富
- **弱点**: 高度なカスタマイズには限界

### 1.10 Bricks

- **概要**: AIパワードのデータ分析プラットフォーム。スプレッドシートデータから数秒でダッシュボード生成
- **強み**: AI が自動でチャート構築・フォーマット・分析を実行
- **弱点**: 新興サービス、エコシステムが未成熟

### 1.11 Metabase (Google Sheets連携)

- **概要**: OSSのBIツール。CData Connect経由でGoogle Sheetsに接続し、ライブダッシュボード作成
- **料金**: OSS版無料 / Pro $85/月 / Enterprise カスタム
- **強み**: 5分でセットアップ完了、非技術者でも使える、自社ホスト可能
- **弱点**: Google Sheets はネイティブ接続ではなくCData等の仲介が必要

## 2. スプレッドシートをバックエンドとして使うツール

### 2.1 Glide

- **概要**: Google Sheets をデータソースにモバイル・Webアプリを構築するノーコードプラットフォーム
- **料金**:
  - Free: 1アプリ, Glide Tables のみ, 10ユーザー
  - Maker: $49/月 (Google Sheets対応, 無制限ユーザー, 500更新)
  - Team: 要問合せ
- **強み**: ノーコード、モバイルファースト、豊富なテンプレート
- **弱点**:
  - **Free プランで Google Sheets 使用不可**（Maker以上が必要）
  - $49-69/月はホビイストには高い（HNで「価格で見送った」との声多数）
  - クライアントサイドの権限制御（セキュリティ懸念）
  - 5,000行を超えるとパフォーマンス劣化
- **技術スタック**: React Native (PWA)

### 2.2 Softr

- **概要**: AIパワードのノーコードプラットフォーム。クライアントポータル、CRM、内部ツール構築
- **料金**:
  - Free: 制限あり
  - Starter: $49/月 (1アプリ, 20ログインユーザー, 2,000レコード)
- **データソース**: Airtable, Google Sheets, HubSpot, Notion, monday.com, SQL (15+)
- **強み**: サーバーサイド権限制御、SOC 2準拠、レコードレベルのパーミッション。最も簡単に使えるとの評価
- **弱点**: 柔軟性とパワーのトレードオフ

### 2.3 Stacker

- **概要**: Google Sheets / Airtable からポータル、ダッシュボード、内部ツールを構築
- **料金**: $59/月〜（無制限アプリ・無制限DB）
- **強み**: スプレッドシートライクなUI、6,000+ツール連携、リアルタイムコラボ
- **弱点**: ネイティブモバイルアプリ非対応、高価格帯

### 2.4 AppSheet (Google)

- **概要**: Google が買収したノーコードアプリビルダー。Google Sheets を直接データソースに使用
- **料金**:
  - Starter: $5/ユーザー/月 (3アプリまで)
  - Core: $10/ユーザー/月 (無制限アプリ)
  - Enterprise Plus: $20/ユーザー/月
- **強み**: Google エコシステムとの深い統合、最安価格帯、ML モデリング（Enterprise）
- **弱点**:
  - **ダッシュボードのカスタマイズ性が低い** — テンプレートが限定的
  - **分析機能が Power BI 等に比べて大幅に劣る**
  - 複雑なアプリには Google Sheets の数式やApp Script知識が必要
  - パーユーザー課金のためチーム拡大でコスト増大（10人Core = $100/月）
- **技術スタック**: Google Cloud

### 2.5 SheetDB

- **概要**: Google Sheets を JSON REST API として公開
- **料金**:
  - Free: 基本機能
  - Hobby: $29.99/月
  - Startup: $49.99/月
  - Business: $129.99/月
- **強み**: シンプルなセットアップ、RESTful API、CRM連携
- **弱点**: API呼び出し数制限、ダッシュボード機能なし（APIレイヤーのみ）

### 2.6 Sheety

- **概要**: Google Sheets を即座にAPIに変換
- **料金**: フリーミアム
- **強み**: 最もシンプル（スプレッドシートURLを貼るだけ）
- **弱点**: 機能が限定的、大規模利用には不向き

### 2.7 Sheet2API

- **概要**: ワンクリックでGoogle Sheets をAPI/CMS化
- **料金**: 従量課金（API呼び出し数ベース）
- **強み**: 従量課金のためスモールスタートしやすい
- **弱点**: API のみでUI構築機能なし

### 2.8 Pory.io

- **概要**: Airtable / Google Sheets からウェブサイト・ポータルを構築
- **料金**: 要確認
- **強み**: テンプレートベースで高速構築
- **弱点**: 「テンプレートの制約が強すぎて特定の使い方しかできない」との批判あり

### 2.9 SpreadSimple

- **概要**: Google Sheets からウェブサイトを即時生成
- **料金**:
  - Starter: $12.90/月
  - Business: $13.90/月
  - Connect: $20.90/月
- **強み**: カスタムドメイン、SEO設定、決済受付対応。コーディング不要
- **弱点**: ダッシュボードというよりウェブサイトビルダー。データ可視化機能は限定的

## 3. オープンソース代替

### 3.1 NocoDB

- **概要**: Airtable のオープンソース代替。既存のリレーショナルDB（MySQL, PostgreSQL等）をスプレッドシートインターフェースに変換
- **GitHub**: nocodb/nocodb (45k+ stars)
- **料金**: セルフホスト無料 / クラウド版有り
- **強み**: 既存DBの上にスプレッドシートUIをかぶせるアプローチ、REST API自動生成
- **弱点**:
  - **ダッシュボード構築機能なし**
  - **ワークフロー自動化機能なし**
  - Google Sheets との連携は n8n 等のワークフローツール経由

### 3.2 Baserow

- **概要**: スタンドアロンのノーコードリレーショナルデータベース
- **GitHub**: baserow/baserow
- **料金**: セルフホスト無料 / クラウド版有り
- **強み**:
  - **ダッシュボード機能内蔵**（NocoDB にはない）
  - ロールベースの権限
  - 自動化機能内蔵
  - API ファーストアーキテクチャ
- **弱点**: スプレッドシートのインポートは可能だが、Google Sheets との直接同期はなし

### 3.3 Metabase

- **概要**: 最も人気のあるオープンソースBIダッシュボードツール
- **GitHub**: metabase/metabase (40k+ stars)
- **料金**: OSS版無料 / Pro $85/月 / Enterprise カスタム
- **技術スタック**: Clojure (バックエンド), React (フロントエンド)
- **強み**:
  - 非技術者でもビジュアルクエリビルダーで操作可能
  - 洗練されたチャート・ダッシュボード
  - セットアップが最も簡単（数分）
  - 運用コストが低い
- **弱点**:
  - Google Sheets への接続は CData Connect 等の仲介が必要
  - SQLベースのため、DB接続が前提（Sheets をDBとして直接は使えない）
  - SSO や高度な埋め込みは商用版のみ

### 3.4 Apache Superset

- **概要**: エンタープライズ対応のオープンソースBIプラットフォーム
- **GitHub**: apache/superset (65k+ stars)
- **料金**: 無料（セルフホスト）/ Preset.io（マネージド版）
- **技術スタック**: Python (Flask), React
- **強み**:
  - SQL ファーストで高度な分析
  - 広範なビジュアライゼーションカタログ
  - 細粒度のRBAC、行レベルセキュリティ
  - 大規模データに強い
  - Preset.io によるマネージドホスティング有り
- **弱点**:
  - セットアップ・運用が複雑（エンジニアリングリソース必要）
  - 非技術者には学習コストが高い
  - Google Sheets の直接接続はなし（DBが前提）

### 3.5 Grafana

- **概要**: 観測性・モニタリング向けのオープンソースダッシュボードプラットフォーム
- **GitHub**: grafana/grafana (66k+ stars)
- **料金**: OSS版無料 / Grafana Cloud 有料プラン有り
- **技術スタック**: Go (バックエンド), React (フロントエンド)
- **強み**:
  - **Google Sheets データソースプラグインが公式提供** (grafana/google-sheets-datasource)
  - スプレッドシートID/URLを入力するだけでダッシュボード作成
  - JWT/APIキー/GCE認証に対応
  - 豊富なビジュアライゼーション
  - アラート機能
- **弱点**:
  - 本来はインフラ監視・時系列データ向けのため、ビジネスダッシュボードには過剰
  - セットアップにある程度の技術力が必要
  - Google Sheets プラグインはライブデータだが、大量データには不向き

### 3.6 Redash

- **概要**: オープンソースのダッシュボード作成ツール。37種類以上のデータソース対応
- **GitHub**: getredash/redash (27k+ stars)
- **料金**: セルフホスト無料
- **技術スタック**: Python, React
- **強み**: Google Sheets 含む多数のデータソース対応、SQLクエリエディタ
- **弱点**: UIが英語のみ、Excel/CSVのローカル接続不可、Databricks買収後に開発が一時停滞（2025年1月にv25リリースで復活）

### 3.7 Grist

- **概要**: スプレッドシートの進化形。リレーショナルスプレッドシート + ダッシュボード
- **GitHub**: gristlabs/grist-core (8k+ stars)
- **料金**: コミュニティ版無料（セルフホスト）/ クラウド版有り / Enterprise 有料
- **技術スタック**: TypeScript, Python (数式エンジン), SQLite (ストレージ)
- **強み**:
  - **スプレッドシートUIとDB機能の融合** — 最もこの市場のニーズに近い
  - ドラッグ&ドロップダッシュボード (チャート, カード, カレンダー)
  - Python 構文の数式サポート
  - 細粒度アクセス制御 (CEO〜インターンまでロール別)
  - セルフホスト可能 (AWS, Azure, Unraid, YunoHost)
  - SQLite ベースで軽量
- **弱点**: Google Sheets からのインポートは可能だが、ライブ同期はなし。知名度が低い

## 4. 市場の欠落点 — ユーザーのペインポイント

### 4.1 Hacker News / Reddit で報告されている不満

**パフォーマンスの壁**:
- Google Sheets は 1,000〜5,000 行を超えると操作が重くなる
- 25,000行でAPI障害が頻発するケース報告 — 「Google Drive の APIは99.99%完全に使い物にならなかった」(HN user: zie)
- Looker Studio のレポートは2〜6分かかることがある

**Google Sheets でのダッシュボード作成の複雑さ**:
- 「Google Sheets でダッシュボードを作るのは *信じられないほど複雑*。Excelなら単純にピボットチャートを作れるのに、Sheetsでは集計列を別途作り、フィルタリングデータを別の列に出し、それを個別にチャートにしなければならない」(HN)
- マルチテーブルのリレーション管理が「指数関数的に難しくなる」

**価格の壁**:
- Glide $49-69/月 — ホビイスト・個人利用者が排除される
- Geckoboard $149/月〜 — 中小企業には高額
- 「個人的に価格で見送った」(HN user: ta988)
- 無料で始められるが、本格利用には急に高額になるパターンが多い

**セキュリティと権限**:
- Google Sheets をバックエンドに使う際、金融データなどのプライバシー懸念
- Glide のクライアントサイド権限制御はセキュリティ的に不安

**開発者体験の不足**:
- 安定した行IDのないAPI
- バージョン管理なし
- デプロイワークフローが未成熟

### 4.2 市場で欠けているもの

1. **「ちょうどいい」ツールの不在**
   - Looker Studio は無料だが遅くて制限が多い
   - 専用ツール（Geckoboard, Klipfolio）は高額
   - ノーコードビルダー（Glide, Softr）はアプリビルダーであってダッシュボードに特化していない
   - OSSツール（Metabase, Superset）はDB前提でSheetsを直接扱えない

2. **スプレッドシートの柔軟性 + ダッシュボードの可視化力の両立**
   - ユーザーは「スプレッドシートのまま」使いたいが、見た目はダッシュボードにしたい
   - 3年以上の開発経験があるチームでも、初期段階では手動スプレッドシートを好むとの調査結果
   - 移行コスト（学習+データ移行）が高く、既存のSheetsを活かせるツールが求められている

3. **軽量セルフホスト型のGoogle Sheets→ダッシュボード変換ツール**
   - Grafana のプラグインは存在するが、Grafana 自体がインフラ監視向けで過剰
   - Grist が最も近いが、Sheets からのライブ同期がない
   - GitHub 上の既存プロジェクトは小規模で保守されていないものが多い

4. **リアルタイム同期 + 見た目の良いダッシュボード + 低価格**
   - この3つを同時に満たすツールがない

5. **日本語対応・日本市場向けの選択肢の少なさ**
   - 多くのツールは英語UI のみ
   - kintone は日本市場に強いがスプレッドシートベースではない
   - Looker Studio が事実上の唯一の日本語対応無料選択肢

## 6. 日本市場

### 6.1 主要プレイヤー

**kintone (サイボウズ)**
- 日本で25,000以上のビジネスチームが利用。JAL等の大手実績
- $24/ユーザー/月（5名〜）。日本語・英語・中国語対応
- ドラッグ&ドロップでアプリ作成、クロス集計、ダッシュボード
- Google Sheets との連携は DBHUB for kintone 等のプラグイン経由
- **ダッシュボード拡張**: krewDashboard (グレープシティ製) で豊富なチャート・ピボット追加
- **強み**: セキュリティが高い、ビジネス利用前提の設計、日本語サポート
- **弱点**: 個人・小規模チームにはオーバースペック、スプレッドシートベースではない

**Notion**
- 日本でも急速に普及中。情報管理・プロジェクト管理として利用
- ページ + データベースの柔軟な組み合わせ
- **弱点**: ダッシュボード・可視化機能が限定的。チャート機能が貧弱
- **使い分け**: 知識整理・プロジェクト基盤 = Notion / 定型業務の記録・運用 = kintone

**Looker Studio (旧 Google データポータル)**
- 日本の中小企業で最も使われるBIツールの一つ
- 完全無料、日本語対応
- Excel脱却の文脈で「スプレッドシート × Looker Studio」が定番パターン
- kintone のデータを Sheets 経由で Looker Studio に送るワークフローも一般的

**Power BI (Microsoft)**
- 日本の中堅・中小企業で最大シェア（20〜30%と推定）
- Excel との親和性が高い
- スプレッドシートユーザーの移行先として定番

### 6.2 日本市場の特徴

1. **Excel/スプレッドシート文化が根強い** — 多くの企業が今もExcel/Sheetsで経営管理
2. **「スプレッドシート × Looker Studio」が定番構成** — 無料で始められる
3. **kintone が業務アプリとして独自ポジション** — 日本製・日本語サポートの安心感
4. **BIツール市場は Power BI がリード** — ただし高価格帯
5. **Redash は日本でも認知されている** — OSSで無料導入可能だが英語UIがネック
6. **「スプシ 可視化」で検索するユーザー層** — 非エンジニアが手軽にデータを見たいニーズ

### 6.3 日本市場で不足しているもの

- **日本語UIで、Google Sheets から直接、美しいダッシュボードを自動生成するツール**
- Looker Studio は無料だが遅い・制限が多い
- kintone はスプレッドシートベースではない
- 海外ツール（Geckoboard, Klipfolio等）は日本語未対応が多い
- 中小企業向けの「安い・簡単・日本語」の三拍子が揃ったツールがない

## 7. 技術的アプローチの分類

### パターン A: スプレッドシートの上にダッシュボードレイヤーを載せる
- Looker Studio, Coefficient, Grafana (Sheets プラグイン)
- Google Sheets をデータソースとして読み取り、別UIで可視化
- **課題**: パフォーマンス（Sheets API制限）、リアルタイム性

### パターン B: スプレッドシートを API/DB として公開
- SheetDB, Sheety, Sheet2API
- Sheets を REST API 化し、フロントエンドは自由に構築
- **課題**: ダッシュボードは自分で作る必要がある

### パターン C: スプレッドシートからアプリを自動生成
- Glide, Softr, AppSheet, Stacker, SpreadSimple
- Sheets のデータ構造を元にUIを自動生成
- **課題**: ダッシュボードに特化していない、アプリビルダーの文脈

### パターン D: スプレッドシートを置き換える
- Rows.com, Grist, NocoDB, Baserow
- より強力なスプレッドシート/DB + ダッシュボード内蔵
- **課題**: 既存 Google Sheets からの移行が必要

### パターン E: BI ツールでDB経由
- Metabase, Superset, Redash
- DB → BI ダッシュボード（Sheets は直接扱えない）
- **課題**: エンジニアリングリソースが必要

### 空白領域（機会）
- **パターン A + C のハイブリッド**: Google Sheets のデータ構造を読み取り、自動的に美しいダッシュボードを生成。リアルタイム同期。低価格。日本語対応。セルフホスト可能
- 既存ツールはいずれもこの組み合わせを完全には実現していない

## 8. 総括

### 市場の現状
- **飽和しているようで実は空白がある** — ツールは多いが「Google Sheets → 美しいダッシュボード」を直接的にシンプルに解決するものは意外と少ない
- Looker Studio が事実上の標準だが、パフォーマンスと使い勝手に大きな不満がある
- ノーコードアプリビルダー（Glide, Softr, AppSheet）はダッシュボード特化ではない
- OSSのBIツール（Metabase, Superset）はDB前提でSheetsを直接扱えない
- 価格帯に「崖」がある — 無料（Looker Studio）と$100+/月の間にちょうどいいツールがない

### 最大の機会
1. **$10-30/月の価格帯で、Google Sheets からワンクリックでダッシュボードを生成するツール**
2. **日本語対応 + シンプルUI + リアルタイム同期**
3. **セルフホスト可能なOSS版 + マネージドSaaS版の両方を提供**
4. **非エンジニアが5分で使い始められる簡易さ**

### 参考: HN での典型的なユーザーストーリー
> Google Sheets にデータがある → ダッシュボードにしたい → Looker Studio は遅い → Glide は高い → AppSheet はダサい → Metabase はDB要る → 結局 Sheets のまま手作業...
