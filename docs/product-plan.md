# Work Dashboard プロダクトプラン

## コンセプト

**スプレッドシートをDBにしたフルカスタマイズWebダッシュボード**

- 既存のスプシを渡すと、それに合ったWebダッシュボードが生成される
- Notionよりも手軽で、カスタマイズ可能で、共有可能
- 部署単位・個人単位でダッシュボードを提供
- 複数スプシの境界線をなくす

## ターゲット

- DXを推進する企業の部署・チーム
- スプシで業務管理しているが、見やすいダッシュボードが欲しい人
- Looker Studioは遅くて使いにくい、有料BIツールは高すぎるという層

## 技術スタック

- **フロントエンド**: Next.js + shadcn/ui + Recharts
- **ホスティング**: Vercel
- **データソース**: Google Sheets API v4
- **リアルタイム同期**: Google Apps Script Webhook
- **認証**: Supabase (Google OAuth)

## アーキテクチャ

### 画面構成

```
┌─────────────┬──────────────────────────────────┐
│  サイドバー   │          メイン画面                │
│             │                                    │
│ 📊 売上管理  │  スプシの内容に応じたダッシュボード   │
│ ✅ タスク    │  - KPIカード                       │
│ 👥 顧客台帳  │  - チャート                        │
│ 📄 ドキュメント│  - テーブル                       │
│             │  - etc.                            │
│  ＋スプシ追加 │                                    │
└─────────────┴──────────────────────────────────┘
```

### データの流れ

```
スプシ登録 → スキーマ自動検出 → パーツ自動選択 → ダッシュボード表示
         → Apps Script Webhook でリアルタイム同期
         → ダッシュボードからスプシへの書き込みも可能
```

### スプシとダッシュボードの対応

- **1スプシ = サイドバーの1アイテム**
- スプシ内に複数シートがあれば、メイン画面内でタブ切り替え
- シートごとにスキーマ検出 → パーツ構成が変わる

### パーツ（ウィジェット）システム

スプシのカラム型を自動推定し、最適なパーツを配置する。

**カラム型の推定ルール:**

| 型 | 判定ロジック | 例 |
|---|---|---|
| date | 日付パース成功 | 2026-03-19, 3/19 |
| number | 数値パース成功 | 1234, -5.6 |
| currency | ¥/$前置 or カンマ区切り | ¥12,000 |
| percentage | %後置 | 85% |
| status | ユニーク値 ≤10 | 未着手/進行中/完了 |
| category | ユニーク値 ≤30 | 営業部, 開発部 |
| text | その他 | 自由記述 |
| url | http始まり | https://... |

**パーツの自動選択:**

| 検出パターン | パーツ |
|---|---|
| 常に | DataTable（洗練されたテーブル） |
| number/currency列あり | KPICard（合計・平均・件数） |
| date + number | TrendLine（折れ線グラフ） |
| status列あり | StatusPie（ステータス分布） |
| category + number | CategoryBar（棒グラフ） |

**カスタマイズ:**
- パーツの並び替え → UIで操作（ドラッグ＆ドロップ）
- パーツの追加・UI設計・実装 → Claude が生成

**パーツのサイズ:**
- `full`: 横幅100%
- `half`: 横幅50%（2つ並ぶ）
- `third`: 横幅33%（3つ並ぶ）

### スプシへの書き込み

ダッシュボードからスプシのデータを直接編集可能にする。
- テーブル行のインライン編集
- ステータスの切り替え（ドロップダウン）
- 新規行の追加

## 実装フェーズ

### Phase 0: ドキュメントページ（今すぐ）
- サイドバーに「📄 ドキュメント」を追加
- markdownファイルの一覧表示 + 内容表示
- このプランドキュメント自体を最初のコンテンツとして表示

### Phase 1: 基盤構築
- スプシ登録の仕組み（設定用スプシ or UI）
- スキーマ自動検出エンジン
- 基本パーツ: DataTable, KPICard
- サイドバーにスプシ一覧表示

### Phase 2: チャートパーツ
- TrendLine（折れ線）
- CategoryBar（棒グラフ）
- StatusPie（円グラフ）
- パーツの並び替えUI

### Phase 3: リアルタイム同期 + 書き込み
- Apps Script Webhook による即時更新
- テーブルからのインライン編集
- ステータス切り替え
- 新規行追加

### Phase 4: 共有と展開
- 特定ドメインのGoogleアカウント許可
- 共有Driveのスプシ対応
- パーツ構成のエクスポート/インポート

## 競合との差別化

| vs | Work Dashboard の優位性 |
|---|---|
| Looker Studio | 速い。シンプル。設定ゼロで使える |
| Notion | スプシとの親和性。既存データの移行不要 |
| Geckoboard等 | 無料〜低価格。日本語完全対応 |
| 自作スプシダッシュボード | 洗練されたUI。書き込み対応。共有可能 |

## 市場の空白

- 無料（Looker Studio）と月$100+の間に「ちょうどいい」ツールがない
- 日本語UIでスプシからダッシュボードを直接作れるツールがほぼ存在しない
